# Security Policy

## Supported versions

FastiraChart is in public preview. Security fixes are made on the latest released version only.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please **do not** open a public issue, discussion or pull request with the details of a security vulnerability.

Report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and
choose **Report a vulnerability**. Include what you found, the affected version, and the steps or a minimal sample
that reproduces it.

If private reporting is not available to you, open a public issue that asks for a private contact **without**
describing the vulnerability, and a maintainer will follow up.

Reports are handled on a best-effort basis by a volunteer maintainer. You will get an acknowledgement, and once a fix
is available the issue will be disclosed in the release notes, with credit to the reporter unless they ask otherwise.
